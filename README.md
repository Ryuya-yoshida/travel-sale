# 旅行セール出発案内 ✈️

3時間ごとに自動で旅行セールの記事を集めて、**自分専用のWebサイト**にまとめるツールです。
毎朝9時ごろには、前日からの新着を **LINE に1通** でお知らせします（設定は任意）。
パソコンを付けっぱなしにする必要はなく、お金もかかりません。

---

## 何をしてくれるか
- Google ニュースと旅行ニュースサイト（Traicy・Aviation Wire・たびりす）から「セール」関連の記事を収集
- ANA・JAL・Peach・ジェットスターなど **航空会社の公式サイトを直接見て**、「販売期間」「販売開始予定」などの新しい告知を検知
- 記事や告知の日付を読み取り、「これから始まるセール」を日付順に表示

---

## しくみ（ざっくり）

- **GitHub**：プログラムを置いておく、ネット上の倉庫。
- **GitHub Actions**：その倉庫で「決まった時間にプログラムを動かしてくれる」無料のロボット。
  このツールでは、3時間ごとにロボットが記事を集め、ページを作り直します。
- **GitHub Pages**：倉庫の中のページを、普通のWebサイトとして公開してくれる機能。

つまり **倉庫に置く → ロボットが定期的に更新 → スマホやPCのブラウザで見るだけ** です。

## セットアップ（はじめての人向け・15分くらい）

### 1. GitHub のアカウントを作る
https://github.com で「Sign up」。メールアドレスがあれば無料で作れます。

### 2. 倉庫（リポジトリ）を作る
1. 右上の「＋」→「New repository」
2. Repository name に `travel-sale` など好きな名前を入れる
3. **Public** を選ぶ（無料で Pages を使うには Public が必要。中身はセール記事のリンクだけなので見られても困りません）
4. 「Create repository」

### 3. ファイルをアップロード
1. 作った倉庫の画面で「uploading an existing file」のリンクを押す
2. zip を解凍した **`travel-sale-watch` フォルダの中身** を全部ドラッグ＆ドロップ
3. 下の「Commit changes」を押す

> ⚠️ `.github` フォルダは「隠しフォルダ」なので、Mac/Windows で見えないことがあります。
> - Mac：Finder で `Command + Shift + .`（ピリオド）を押すと表示されます
> - Windows：エクスプローラーの「表示」→「隠しファイル」にチェック
>
> アップロード後、倉庫に `.github/workflows/watch.yml` があればOKです。

### 4. ロボットに書き込み許可を出す
**Settings → Actions → General** を開き、一番下の「Workflow permissions」で
**Read and write permissions** を選んで「Save」。
（ロボットが新しいページを倉庫に保存するために必要です）

### 5. Webサイトとして公開する
**Settings → Pages** を開き、
- Source：**Deploy from a branch**
- Branch：**main** と **/docs** を選んで「Save」

1〜2分すると、上部に `https://あなたのユーザー名.github.io/travel-sale/` のようなURLが表示されます。
これがあなた専用のセール一覧ページです。スマホのホーム画面に追加しておくと便利です。

### 6. 最初の1回を動かす
**Actions** タブ →（「ワークフローを有効にしますか？」と出たら有効化）→ 左の「旅行セール巡回」→ 右の **Run workflow** → 緑の **Run workflow**。

1〜2分で緑のチェック ✅ が付けば成功です。少し待ってから、手順5のURLを開いてください。
以降は放っておけば3時間ごとに自動で更新されます。

## LINE で毎朝お知らせを受け取る（任意・20分くらい）

自分だけが友だちの「LINE公式アカウント」を作り、そこから自分に送ります。
無料プラン（月200通）で、1日1通＝月30通ほどなので十分足ります。

### A. LINE公式アカウントを作る
1. https://entry.line.biz/start/jp/ を開き、「LINE公式アカウントをはじめる」→ 自分のLINEアカウントでログイン
2. アカウント名（例：セール通知）などを入力して作成。業種は「個人」系など適当でOKです

### B. Messaging API を有効にする
1. 作成後に開く **LINE Official Account Manager** の右上「設定」→ 左メニュー「Messaging API」→「Messaging APIを利用する」
2. 「プロバイダー」は新規作成（名前は自分の名前などでOK）→ 残りはそのまま進めて完了

### C. 2つの値をメモする
https://developers.line.biz/console/ を開き、作ったプロバイダー → チャネル（アカウント名と同じ名前）を選びます。

1. **「チャネル基本設定」タブ** の一番下にある **「あなたのユーザーID」**（`U` で始まる長い文字列）をコピー
2. **「Messaging API設定」タブ** の一番下 **「チャネルアクセストークン（長期）」** の「発行」を押してコピー
3. 同じタブにある **QRコード** を自分のスマホで読み取って、公式アカウントを **友だち追加**
   （友だちになっていないと届きません）

### D. GitHub に登録する
倉庫の **Settings → Secrets and variables → Actions** で「New repository secret」を2回：

| Name | Secret（入れる値） |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | C-2 のチャネルアクセストークン |
| `LINE_USER_ID` | C-1 のユーザーID |

さらに同じ画面の **Variables タブ** → 「New repository variable」で
`PAGE_URL` に一覧ページのURL（手順5のURL）を登録すると、メッセージの最後にリンクが付きます。

> トークンは「パスワード」と同じです。Secrets 以外（config.yaml など）には書かないでください。

### E. テスト送信
**Actions → 旅行セール巡回 → Run workflow** で、**「LINE にも送る（テスト用）」にチェック** を入れて実行。
LINE にお知らせが届けば完了です。以降は毎朝自動で届きます。

### 届くメッセージの例
```
✈️ 旅行セールのお知らせ 10/7

■ 新着 2件
★ジェットスター 10月10日から半額セール予告（10/10(土)〜）
https://...
・じゃらん 秋のクーポン配布
https://...

■ 1週間以内に始まるセール
10/10(土) ジェットスター 10月10日から半額セール予告

📋 一覧ページ
https://あなたのユーザー名.github.io/travel-sale/
```

- 新着が無い日も「新着 0件」と届くので、ちゃんと動いているか確認できます
- GitHub の混雑で、届くのが9時を数分〜数十分過ぎることがあります
- 時間を変えたいときは `.github/workflows/watch.yml` の `"50 23 * * *"` を変更します（UTC表記なので日本時間から9時間引く。例：朝7時ごろなら `"50 21 * * *"`）。**同じファイル内の `if:` の行の時刻も同じ値に** 変えてください
- 友だち追加したとき自動で返事が来るのが気になる場合は、Official Account Manager の「設定 → 応答設定」で「応答メッセージ」をオフにできます

## ページの見方
- **これから始まるセール**：記事タイトルに日付があるものを、開始が近い順に表示
- **最近の記事**：日付が読み取れなかった記事を新しい順に表示
- <span style="color:#e8364f">NEW</span>：この24時間で新しく見つかった記事
- **予告・開始**：「予告」「開始」などの言葉を含む記事
- 上の検索欄で「ANA」「ハワイ」などと入れると絞り込めます

## 公式サイトの見張りについて
`config.yaml` の `watch_pages` に並んだ公式ページを3時間ごとに読み、
「セール」「販売期間」「販売開始」などを含む文のうち **前回は無かったもの** を新着として載せます。
（例：ANAのページに「2026年10月20日（火）0:00からの販売開始を予定」と出たら、その日付で「これから始まるセール」に並びます）

一覧ページの一番下 **「見ているサイト」** で、各サイトを読めているか確認できます。
- **○**：読めています
- **× アクセスを拒否された可能性**：そのサイトがプログラムからのアクセスを止めています。ニュース経由で拾える情報で補います
- **× JavaScriptで表示するサイトの可能性**：見た目はブラウザが後から組み立てるタイプで、この方法では中身が読めません

× が続くサイトは `watch_pages` から消してもOKです。見たいサイトを足すときは、同じ形で `name` と `url` を追加してください。

## カスタマイズ（config.yaml）
倉庫で `config.yaml` を開き、鉛筆アイコン ✏️ で編集 →「Commit changes」で保存できます。

- `google_news_queries`：検索ワード。よく行く場所や好きな航空会社を足すと便利です（例：`ハワイ 航空券 セール`）
- `announce_keywords`：「予告・開始」マークを付ける言葉
- `watch_pages`：セール告知ページのURLを入れておくと、ページの中身が変わったときに一覧へ【ページ更新】として載ります
- 更新間隔：`.github/workflows/watch.yml` の `cron`（例：毎時なら `"7 * * * *"`）

## うまく動かないとき
- **Actions で赤い ✖**：クリックすると原因が見られます。`Permission denied` なら手順4を確認
- **LINE が届かない**：「LINE 送信に失敗: 401」ならトークンの貼り間違い、「400」ならユーザーIDの間違いか友だち追加していない可能性があります
- **ページが 404**：手順5の設定後、最初の実行が終わるまで数分待ってください
- **しばらく更新されない**：GitHub は混雑時に数十分遅れることがあります。また60日ほど倉庫に変化がないと自動実行が止まることがあるので、その場合は Actions タブで再度有効化してください

## 注意
記事タイトルからの自動判定なので、関係ない記事が混ざったり日付を読み違えることがあります。予約前に必ずリンク先で条件を確認してください。
